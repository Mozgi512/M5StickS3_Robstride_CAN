# M5StickS3 で Robstride を CAN で動かす最小サンプル

M5StickS3 の Grove ポートに CAN トランシーバをつなぎ、Robstride モータ 1 台を位置制御（CSP）で往復させるだけのサンプルです。コードは [`src/main.cpp`](src/main.cpp) の 1 ファイルだけです。

## 動き

1. ID 1〜127 に問い合わせ（Type0）を送り、返事をした Robstride を見つける
2. CSP（位置制御）モードにして励磁する。そのときの位置を中心にする
3. 中心 ±90°、周期 4 秒の正弦波で往復させる（10 ms ごとに目標角を送る）

ボタン A（表の大きいボタン）で停止（脱力）/ 再開。画面に ID・状態・角度を表示します。

## 必要なもの

- M5StickS3
- CAN トランシーバ（ESP32 内蔵の CAN コントローラ TWAI と CAN バスの間に入れるもの）
- Robstride モータ（EDULITE 05 / RS0x シリーズ）と、その電源
- 120Ω 終端抵抗（バスの両端。モジュールやモータに内蔵されていれば不要）

## 配線

```
M5StickS3 Grove             CAN トランシーバ          Robstride
---------------             ----------------          ---------
白  G9  (CAN TX) ─────────  TXD（MCU からの入力）
黄  G10 (CAN RX) ─────────  RXD（MCU への出力）
赤  5V           ─────────  VCC
黒  GND          ─────────  GND
                            CANH ─────────────────── CANH
                            CANL ─────────────────── CANL
```

- **トランシーバの電源電圧を確認してください。** 3.3V 専用の品に Grove の 5V を入れると壊れます。その場合は 3.3V を別に用意し、`src/main.cpp` の `GROVE_5V` を `false` にします。
- 動かないときは、まず TX と RX の入れ違いを疑ってください（`CAN_TX` / `CAN_RX` を入れ替える）。
- ビットレートは 1 Mbps（Robstride の既定）です。

## ビルドと書込み

[PlatformIO](https://platformio.org/) を使います。

```sh
pio run -t upload -t monitor
```

使っている pioarduino のバージョンには StickS3 のボード定義が無いため、`boards/m5stack-sticks3.json` を同梱しています。

## プログラムの中身

### CAN フレーム（Robstride プライベートプロトコル）

拡張 ID（29 bit）にコマンドの種類と宛先を入れ、データ 8 バイトに値を入れます。

```
ID   = 通信タイプ[28:24] | ホストID 0xFD[23:16] | 0[15:8] | 宛先モータID[7:0]
応答 = 通信タイプ[28:24] | ...                  | モータID[15:8] | ...
```

| 通信タイプ | 用途 | データ |
| --- | --- | --- |
| 0 | 問い合わせ（モータを探す） | なし |
| 3 | 励磁 | なし |
| 4 | 停止（脱力） | byte0 = 1 で故障もクリア |
| 17 | パラメータ読出し | byte0-1 = インデックス → 応答の byte4-7 に値 |
| 18 | パラメータ書込み | byte0-1 = インデックス、byte4-7 = 値（リトルエンディアン） |

使っているパラメータ:

| インデックス | 名前 | 型 | 値 |
| --- | --- | --- | --- |
| `0x7005` | run_mode | uint8 | 5 = CSP（位置制御） |
| `0x7016` | loc_ref | float | 目標角 [rad] |
| `0x7017` | limit_spd | float | 速度上限 6 rad/s |
| `0x7018` | limit_cur | float | 電流上限 5 A |
| `0x700B` | limit_torque | float | トルク上限 4 Nm |
| `0x701E` | loc_kp | float | 位置ゲイン 5 |
| `0x7019` | mech_pos | float | 今の角度 [rad]（読出し） |

### 立上げ手順（`enableCsp()`）

1. Type4（故障クリア付き停止）
2. run_mode = 5、各上限とゲインを書込み
3. mech_pos を読み、loc_ref = 今の位置 にする（励磁した瞬間に古い目標へ飛ばないように）
4. Type3 で励磁、もう一度 run_mode = 5 と loc_ref を書く

あとは `loop()` で 10 ms ごとに loc_ref を書き込むだけで、モータがその目標に追従します。

## 注意

- 初めて動かすときは、モータの出力軸に何もつけず、固定した状態で試してください。
- 非常停止はありません。モータ電源をすぐ切れるようにしておいてください。
