# M5StickS3 で Robstride を動かすスケッチ例

絶縁 CAN トランシーバーモジュールキットを使い、M5StickS3 から Robstride モータを CAN で動かすスケッチです。

## 動作

1. CAN バス上の Robstride を探す（ID 1〜127）
2. 位置制御（CSP）モードで励磁する。そのときの位置を中心にする
3. 中心 ±90°、周期 4 秒で往復させる

| 操作 | 動作 |
| --- | --- |
| ボタン A（表の大きいボタン） | 停止（脱力）/ 再開 |

画面にモータの ID、状態、角度を表示します。

## 必要なもの

- 絶縁 CAN トランシーバーモジュールキット
- M5StickS3
- Grove ケーブル
- Robstride モータ（EDULITE 05 / RS0x シリーズ）と、その電源

## 接続

```
M5StickS3 ──Grove ケーブル── モジュール ──CANH / CANL── Robstride
```

M5StickS3 の Grove ポートとモジュールの Grove ソケットを Grove ケーブルでつなぎます。モジュールの電源は Grove の 5V から取ります（モジュール上で 3.3V に変換します）。

| Grove | M5StickS3 | モジュール |
| --- | --- | --- |
| 黒 | GND | GND |
| 赤 | 5V | 5V（AMS1117 で 3.3V に変換） |
| 白 | G9（CAN TX） | TXD（CTM8251KAT への入力） |
| 黄 | G10（CAN RX） | RXD（CTM8251KAT からの出力） |

CAN 側は 2P ターミナル（またはピンヘッダ H/L）で Robstride につなぎます。

| ターミナル | 接続先 |
| --- | --- |
| H | Robstride の CANH |
| L | Robstride の CANL |

### 終端抵抗

CAN バスには両端に 120Ω の終端抵抗が必要です。このモジュールはバスの端に置くので、終端抵抗スイッチで 120Ω を入れてください。もう一方の端（いちばん遠いモータ側）にも 120Ω をつけます。

### ピンヘッダ（4P）で M5StickS3 以外のマイコンとつなぐ場合

| ピン | 内容 |
| --- | --- |
| GND | GND |
| 3V3 | 3.3V 電源（トランシーバーの電源に直接つながる） |
| TXD | マイコンの CAN TX からつなぐ |
| RXD | マイコンの CAN RX へつなぐ |

ピンヘッダから給電するときは 3.3V を入れてください。5V を入れる場合は Grove ソケットの 5V から入れます。

## 書込み

[PlatformIO](https://platformio.org/) で書き込みます。

```sh
pio run -t upload -t monitor
```

## うまく動かないとき

画面に `not found` が出続けるときは、次を確認してください。

- Robstride の電源が入っているか
- CANH と CANL が入れ違っていないか
- 終端抵抗スイッチが入っているか
- Grove ケーブルがしっかり挿さっているか

## プログラムの解説

### CAN フレーム（Robstride プライベートプロトコル）

ビットレートは 1 Mbps です。拡張 ID（29 bit）にコマンドの種類と宛先を入れ、データ 8 バイトに値を入れます。

```
ID   = 通信タイプ[28:24] | ホストID 0xFD[23:16] | 0[15:8] | 宛先モータID[7:0]
応答 = 通信タイプ[28:24] | ...                  | モータID[15:8] | ...
```

| 通信タイプ | 用途 | データ |
| --- | --- | --- |
| 0 | 問い合わせ（モータを探す） | なし |
| 3 | 励磁 | なし |
| 4 | 停止（脱力） | byte0 = 1 で故障もクリア |
| 17 | パラメータ読出し | byte0-1 = インデックス → 応答の byte4-7 に値 |
| 18 | パラメータ書込み | byte0-1 = インデックス、byte4-7 = 値（リトルエンディアン） |

使っているパラメータ:

| インデックス | 名前 | 型 | 値 |
| --- | --- | --- | --- |
| `0x7005` | run_mode | uint8 | 5 = CSP（位置制御） |
| `0x7016` | loc_ref | float | 目標角 [rad] |
| `0x7017` | limit_spd | float | 速度上限 6 rad/s |
| `0x7018` | limit_cur | float | 電流上限 5 A |
| `0x700B` | limit_torque | float | トルク上限 4 Nm |
| `0x701E` | loc_kp | float | 位置ゲイン 5 |
| `0x7019` | mech_pos | float | 今の角度 [rad]（読出し） |

### 励磁の手順（`enableCsp()`）

1. Type4（故障クリア付き停止）
2. run_mode = 5、各上限とゲインを書き込む
3. mech_pos を読み、loc_ref = 今の位置 にする（励磁した瞬間に古い目標へ飛ばないように）
4. Type3 で励磁し、もう一度 run_mode = 5 と loc_ref を書き込む

励磁したあとは、`loop()` で 10 ms ごとに loc_ref を書き込みます。モータはその目標に追従します。

## 注意

- 初めて動かすときは、モータの出力軸に何もつけず、モータを固定した状態で試してください。
- 非常停止はありません。モータの電源をすぐ切れるようにしておいてください。
